# Ticket Management System

BCA 4th-Semester Project

## XAMPP Setup

1. Install XAMPP.
2. Start Apache.
3. Start MySQL.
4. Copy the project folder to `C:\xampp\htdocs\ticket-management-system\`.
5. Open phpMyAdmin (`http://localhost/phpmyadmin/`).
6. Create a database named `ticket_management_system` and import `database/ticket_management_system.sql`.
7. Check `config/database.php` for credentials.
8. Open the project in your browser: [http://localhost/ticket-management-system/](http://localhost/ticket-management-system/)
